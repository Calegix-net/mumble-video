# Security Policy

This is a fork of Mumble that adds video and screen sharing. This policy covers the fork.

## Supported Versions

Fixes land on `main` and ship in the `dev-latest` release and the newest tagged release. Older builds are not patched.

## Reporting a Vulnerability

Please report vulnerabilities in private through GitHub:
<https://github.com/Calegix-net/mumble-video/security/advisories/new>

Do not open a public issue or pull request for a security bug.

A useful report says which build and platform you used, how to reproduce the problem, and what an attacker gains from it.

We will do our best to respond, verify the report and fix it as quickly as possible.

If the bug is also present in upstream Mumble, please report it to the Mumble project as well at security@mumble.info.

## Security Advisories

Advisories for this fork are published at <https://github.com/Calegix-net/mumble-video/security/advisories>.

Upstream Mumble advisories are published at <https://www.mumble.info/security/>.
